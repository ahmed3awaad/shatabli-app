# شطبلي — التطبيق

صنايعية ومساعدين لأي حاجة في البيت، بأسعار واضحة. نسخة تجريبية للقاهرة الجديدة.

- الواجهة: HTML + JavaScript، من غير build step.
- الداتابيز وتسجيل الدخول: Supabase. الإعداد في `supabase/setup_all.sql`.
- `config.js` فيه المفتاح العام بس (publishable). الحماية في قواعد Row Level Security في الداتابيز.

الأيقونات من [Lucide](https://lucide.dev) (ISC License). الصور من Unsplash.
